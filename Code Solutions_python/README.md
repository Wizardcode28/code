# Computer Networks Lab Solutions (Python)

All lab solutions mapped strictly 1-to-1 to the 10 rows of `lab_experiments.png`:

| S. No. | Lab Manual Topic | Manual Lab # | Solution File |
|---|---|---|---|
| 1 | Basics of Linux/Unix and Configuration of a simple network topology using switch over Cisco Packet Tracer | 1 | `lab1_linux_switch_topology.py` |
| 2 | Basics of socket programming and binding of client server machines | 2 | `lab2_socket_programming_binding.py` |
| 3 | Client server application for chat (exchange of messages) | 3 | `lab3_client_server_chat.py` |
| 4 | PC to PC file transfer using serial port | 4 | `lab4_serial_file_transfer.py` |
| 5 | Implementation of flow control protocols (Stop and Wait, Sliding Window) | 5 | `lab5_flow_control_stop_wait_sliding_window.py` |
| 6 | Implementation of error control & detection protocols (Parity, Stop-and-Wait ARQ, GBN ARQ, Selective-Reject ARQ, VRC, LRC, CRC) | 6-7, 8 | `lab6_error_detection_control_arq.py` |
| 7 | Implementation of Hamming code for multi-bit error detection and single-bit error correction | 9 | `lab7_hamming_code.py` |
| 8 | Implementation of CSMA/CD, non-persistent, 1-Persistent and P-Persistent CSMA protocols | 10-11 | `lab8_csma_protocols.py` |
| 9 | Implementation of various routing protocols (RIP and OSPF) | 12-13 | `lab9_routing_rip_ospf.py` |
| 10 | Implementation of TCP/IP echo | 14 | `lab10_tcp_ip_echo.py` |

---

### Features:
- **Interactive Prompts**: All scripts take input dynamically from the user via `input()` with sensible defaults on Enter.
- **Header Sample Inputs**: Each file starts with comments specifying the exact sample inputs expected.
- **Short & Simple Logic**: Minimal and clean logic without verbose clutter.

Socket- simply an endpoint of communication btw 2 computers.
- software endpoint that allows 2 programs to pass data back and forth across a network.
- It combined IP Address & Port no.

Socket programming is process of writing code to create these endpoints, 
link them & exchange information btw a client and a server.
It follows a client-servel model where one program waits for call and other
program reaches out.

- Server opens a socket, binds to a port and listens for requests.
- Client opens a socket and dials the server's address to start a link.

IP Address points to connect computer on network.
Port no. points to correct app running on that computer.

Communication flow

1) Server Side
Create socket
Bind IP + Port
listen
Accept Client
Receive message
Send Reply
Close

2) Client Side
Create Socket
Connect Server
Send message
Receive Reply
Close

| Method                  | Parameters                              | Purpose                                   |

| `close()`               | None                                    | Close the socket                          |

TCP = SOCK_STREAM, UDP = SOCK_DGRAM.
The server must bind() to a known IP and port; the client usually does not, because the OS automatically assigns an ephemeral port.
connect() takes a single address tuple (IP, port).
send() transmits bytes, so use .encode() on strings.
recv(n) returns bytes, so use .decode() to convert them back to a string.
accept() returns a new socket for communication and the client's address, while the original server socket continues listening for other connections.

Ques: If i give Server IP 0.0.0.0 then can i give same IP to Client and will this work?
Explain: 
On server with bind it works server.bind(("0.0.0.0",5000))
means listen for connections on all network interfaces of this network.

For example, your server PC might have:
Wi-Fi:      192.168.1.10
Ethernet:   192.168.1.20
localhost:  127.0.0.1

With 0.0.0.0, server listens on all of them at port 5000

On Client don't do this: client.connect(("0.0.0.0",5000))
Because 0.0.0.0 isn't an actual destination address. It means all local network
interfaces when used for binding/listening, this is not server address.

Client needs actual IP address of server.
we can use client.connect(("127.0.0.1", 5000)) (localhost)
or another IP address
